# Проверка версии 0.1.0

## Автоматические проверки

- `go test -race ./...`: модель навигации, границы и обратимость переходов, XML/EPUB/ZIP parsers, очистка HTML, archive traversal, локальная авторизация, HTTP Range и prepare/ready/commit.
- `go vet ./...`: статический анализ Go-кода.
- `scripts/smoke.cjs`: Microsoft Edge, viewport 1600×1100. Библиотека содержит пять книг; каждый файл открывается, переход вперёд/назад в развороте меняет пару с шагом 2, режим прокрутки — с шагом 1. Проверены отсутствие JavaScript/HTTP-ошибок и общая ревизия у двух подключённых представлений.
- PDF `diletant-2025-121.pdf`: 100 физических страниц. Остальные книги успешно пагинируются; число экранных страниц зависит от окна и шрифта.
- Два браузерных представления подтвердили одинаковую ревизию и показали соседние страницы 4 и 5.
- `scripts/native-smoke.ps1`: Windows EXE создал два видимых top-level окна на разных дисплеях, после чего тестовый экземпляр корректно закрыт. Это проверка host, а не полное ручное тестирование читательского UX.

Скриншоты браузерного прогона находятся в `dist/library.png`, `dist/pdf-reader.png`, `dist/epub-reader.png`, `dist/fb2-reader.png` и `dist/fb3-reader.png`. Эти файлы диагностические и не встроены в EXE.

## Перед выпуском следующей версии на целевом UX8407AA

- [ ] Проверить полноэкранный режим на обоих экранах, F11/Esc и обмен страницами.
- [ ] Проверить соответствие номеров дисплеев в Windows и физического расположения после поворота.
- [ ] Проверить масштаб Windows 100/150/200%, разные DPI и сохранение чёткости PDF.
- [ ] Проверить сон, пробуждение, временное отключение второго дисплея и возврат в два окна.
- [ ] Проверить сенсорные жесты на обоих экранах, тачпад и быстрое колесо.
- [ ] Проверить защищённый PDF и отказ от ввода пароля.
- [ ] Провести двухчасовое чтение с измерением RAM, CPU/GPU и батареи.
- [ ] Проверить чистую установку WebView2 Runtime и запуск без инструментов разработки.

Подписанный installer и автоматическое обновление в эту версию не входят.
