# Duo Reader

Локальный двухэкранный ридер на Go для Windows 11. PDF, EPUB, FB2, FB2.ZIP и FB3 открываются без подключения к интернету. PDF отображает встроенный PDF.js; текстовые форматы разбираются на Go и получают общую книжную вёрстку.

## Запуск

Запустите `dist/DuoReader.exe`. Нужен Microsoft Edge WebView2 Runtime (обычно уже установлен в Windows 11). Каталог `books` ищется рядом с EXE, на уровень выше и в текущем рабочем каталоге; можно указать его явно:

```powershell
.\dist\DuoReader.exe -books .\books
.\dist\DuoReader.exe "C:\Books\magazine.pdf"
```

Первое окно назначается дисплею `DISPLAY1`, второе — `DISPLAY2`: это исходное соответствие «экран Windows №1 — левый, №2 — правый». Дисплеи сортируются по числу в имени Windows GDI, а не по физическому расположению. Для необычной конфигурации можно обменять страницы кнопкой `⇄`. На одном мониторе второе окно скрыто, а первое показывает две страницы.

Выберите книгу на полке или нажмите «Открыть». Перетащить файл можно в любое окно. Импортированные файлы копируются в каталог настроек; оригиналы открываются только для чтения. Сеанс, закладки, настройки и диагностический `reader.log` сохраняются локально в `%LocalAppData%\DuoReader`. Параметр `-data` меняет этот каталог. Для удаления импортированных копий удалите соответствующие подкаталоги `import-*` при закрытом приложении.

## Управление

| Действие | Управление |
|---|---|
| Следующий/предыдущий разворот | `→` / `←`, `Page Down` / `Page Up`, `Space` / `Shift+Space` |
| Открыть файл | `Ctrl+O` |
| Поиск в книге | `Ctrl+F`, введите текст и нажмите «Найти» |
| Начало/конец | `Home` / `End` |
| Полноэкранный режим | `F11` или `⛶` |
| Перейти к странице | Поле номера внизу |
| Масштаб PDF | `−`, `+`, `Ctrl+колесо`; кнопка «Страница» / «По ширине» |
| Шрифт текстовой книги | `A−` / `A+` |
| Оглавление и закладки | `☷`, `☆` |
| Тема | `◐`: светлая, сепия, тёмная |
| Обмен экранов / RTL / отдельная обложка | `⇄` / `RTL` / «Обложка» |

В режиме «Разворот» обе страницы меняются с шагом 2. В режиме «Прокрутка» колесо/вертикальный жест сначала прокручивает увеличенные PDF-страницы, затем сдвигает пару с шагом 1: `1–2 → 2–3 → 3–4`; назад — обратная последовательность. Когда страница целиком помещается в окно, колесо сразу сдвигает пару. Это первая реализация прокрутки с переходом через границу; свободная инерционная лента остаётся следующим этапом.

В обоих окнах используется одна сессия. Новый разворот показывается после подтверждения готовности от всех подключённых представлений. Закрытие любого нативного окна завершает приложение.

## Сборка и тесты

Требуется Go 1.24 или новее. C/C++-компилятор и Node.js для сборки не нужны. PDF.js 6.4.299 уже включён в исходники.

```powershell
go test ./...
go build -buildvcs=false -trimpath -ldflags="-s -w -H windowsgui" -o dist/DuoReader.exe ./cmd/duoreader
```

Из Linux/WSL:

```bash
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -buildvcs=false -trimpath -ldflags='-s -w -H windowsgui' -o dist/DuoReader.exe ./cmd/duoreader
go test -race ./...
```

Приложение включает режим диагностики и тестирования в обычном браузере. Используйте консольную сборку (`scripts/build.ps1 -Console`) или `go run ./cmd/duoreader`:

```powershell
.\dist\DuoReader.exe -serve -listen 127.0.0.1:18765 -data .\test-session
```

Откройте адрес с токеном, выведенный в консоли. Сервер слушает только localhost по умолчанию. Доступ требует случайного токена сессии и защищён cookie; файлы доступны только для текущей книги. Для автоматической проверки UI нужен установленный Playwright и Microsoft Edge:

```powershell
node scripts/smoke.cjs "http://127.0.0.1:18765/?token=..."
```

Тесты парсеров используют `books/`, если каталог присутствует; для CI без книг есть синтетические проверки навигации, безопасности XML/HTML/ZIP, HTTP Range и синхронизации. Пользовательские книги не встроены в EXE.

## Текущий объём и ограничения

Реализована первая функциональная версия, а не все производственные этапы [TASK.md](TASK.md). Доступны оба шага навигации, два нативных окна, DPI awareness, восстановление сессии, обложка, RTL, поворот PDF, оглавление и закладки. Все пять предоставленных файлов используются в проверках адаптеров.

- EPUB пока получает единую вёрстку приложения: издательские CSS, fixed-layout, SVG/MathML, embedded fonts и мультимедиа не воспроизводятся. Скрипты и удалённые ресурсы запрещены.
- FB2.ZIP с несколькими книгами выдаёт понятную ошибку; нужно выбрать книгу после распаковки.
- Номера страниц EPUB/FB2/FB3 пересчитываются при изменении шрифта или размеров окна. Сохранение логического места пока приблизительное, по идентификатору блока.
- Нет редактирования/аннотаций PDF, OCR, DRM, обновлений, подписанного установщика и интеграции с Microsoft Store.
- Настоящий двухэкранный UX с поворотом, сенсорными жестами, сном и отключением встроенного дисплея нужно отдельно проверить на UX8407AA.
- Поиск показывает страницу с совпадением; подсветки и общего списка результатов пока нет. Текст PDF можно выделять и копировать обычным `Ctrl+C`.

Зависимости и причины выбора движка перечислены в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) и [THIRD_PARTY.md](THIRD_PARTY.md).
